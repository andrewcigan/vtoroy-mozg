# Версия воркшопа: чем отличается от Ивы 0.5.14

- **Голос.** `DEEPGRAM_API_KEY` задан — Deepgram. Нет — `OPENROUTER_API_KEY`, модель `OPENROUTER_STT_MODEL`
  (по умолчанию `openai/gpt-4o-mini-transcribe`). Звук видео и кружков достаёт ffmpeg.
- **Память.** Правила — `agent/instructions/35-vtoroy-mozg.md`. Вид записки — последняя метка `вид:…`.
- **Экран.** `/mozg`, «покажи мой мозг» — списки и карточки; `/tablica`, «пришли мозг таблицей» — Excel.
  Живёт в мосте, токенов не тратит, секреты вырезает исходящий гейт.
- **Мой слой.** `iva sloy <папка>`: правила, навыки, файл о себе. Чужие файлы не затирает.
- **Сама не пишет.** При первой установке `proactive` выключен, потолок 500 000 токенов в день. Это
  осознанное отличие от ADR-0020: участник воркшопа платит за каждый ход. Включить: `iva proactive on`.
- **Версии.** Свои теги `v100.x.y`; теги автора в этот репозиторий не переносим, иначе установщик выберет их.
- **Обновления автора** сюда не приходят сами.
